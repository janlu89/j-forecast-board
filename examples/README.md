# Examples

| File | What it is |
|---|---|
| `sample_store_sales.csv` | **Made-up** daily sales of three shops (Milano, Roma, Napoli) with a promo flag, in the Italian Excel format (`;` and decimal commas). Use it to try the **Your data** tab. |
| `quickstart_cli.py` | The original command-line demo: one Timestral forecast with a chart. Needs the optional extra: `pip install -e ".[examples]"`. |
